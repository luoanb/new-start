# 视觉设计文档格式

本文件是 `requirement-authoring` Skill 的可选执行资料，不是独立权威规则。视觉设计不得成为需求文档之外的产品行为来源。

```markdown
# <需求名称>视觉设计

> 文档状态：<草案|待确认|生效|废弃>
> 所属需求：`需求.md`
> 上位依据：《需求契约追溯规则》
> 适用范围：<涉及的页面或交互区域>
> 下位产物：界面实现与视觉验收结果

## 二、页面结构

<页面区域、信息层级和主要组件>

## 三、交互状态

<加载、空白、正常、禁用、错误、成功等状态的视觉表现>

## 四、视觉约束

<布局、尺寸、间距、颜色、字体、响应式和无障碍要求>

## 五、待确认项

- vq{n}: <尚未确认的视觉选择或“无”>
```

如果某项内容决定按钮何时可用、操作产生什么结果、错误如何处理或怎样才算验收通过，必须先同步到 `需求.md`。
