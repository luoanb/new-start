# file_info

## 工具

返回活动工作区内文件或目录的元信息。

参数：

- `path`（必填）：相对活动工作区根路径的路径。

返回 JSON：`path`、`exists`、`is_dir`、`size`、`modified_ms`、`binary`。

## 对模型的期待

- 需要判断目标是否存在、是文件还是目录、是否二进制文件、大小或修改时间时调用。
- 写操作前用 `file_info` 确认目标类型（避免覆盖目录等误操作）。

## 忌用

- 不要用它获取文件内容——那是 `read_file` 的职责。
- 不要对工作区之外的路径调用（会被拒绝）。

## 注意

- 只作用于当前 active 工作区。
- `binary` 字段基于内容探针判断，小文件可能不准确。
