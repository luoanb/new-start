# delete_file

## 工具

删除活动工作区内的一个或多个文件或目录（目录递归删除）。对应 IDE 的 DeleteFile 能力。

参数：

- `paths`（必填）：相对活动工作区根路径的路径数组，可一次删除多个。

所有路径必须存在且位于工作区根路径之内，否则报错。**没有撤销**。

## 对模型的期待

- 用户明确要求删除文件/目录时调用。
- 删除前先确认目标内容（必要时 `read_file` 或 `list_directory` 核对），再执行。
- 删除后告知用户已删除哪些路径。

## 忌用

- 不要在未确认用户意图时擅自删除文件——删除不可恢复。
- 不要删除工作区之外的路径（会被拒绝）。
- 不要用 `delete_file` 做清理临时文件的惯用动作之外的用途。

## 注意

- 只作用于当前 active 工作区。
- 目录会递归删除，谨慎使用。
