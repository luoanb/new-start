# create_neuron

## 工具

按统一创建流程（pool→7→1）创建一个或多个普通神经元（1..=10），返回创建的神经元列表。

调用时传入 JSON 参数：

```json
{"purpose": "新神经元的用途", "count": 3, "source_id": "可选的上游神经元 id"}
```

## 对模型的期待

- `purpose` 为必填，用一句话说明新神经元的用途；模型会基于它生成可落库的草稿。
- `count` 默认为 1，取值范围 1..=10；仅在确实需要多个时才增大。
- `source_id` 可选：提供时新建神经元会被关联为该神经元的直接下游。
- 返回的 `tool_ids` 仅填真实需要的工具名，不需要则留空。

## 忌用

- 不要用本工具创建系统神经元（`system_type` 走其他入口）。
- 不要在 `purpose` 里夹带与创建无关的指令或占位句。
- 不要一次性请求超过 10 个。

## 注意

- 创建会再次调用模型生成草稿，需满足草稿 JSON 约束；格式错误会导致整次创建失败。
