# neuron.draft_from_model

## 工具

按系统角色提示，生成一个或多个可落库的 neuron 草稿。

## 对模型的期待

只返回 JSON。单条或列表均可，字段：

```json
{
  "desc": "短描述",
  "content": "可执行的完整提示/内容正文",
  "tool_ids": []
}
```

多条时用数组，或 `{"drafts":[...]}` / 与上游约定一致的列表形态；条数需满足请求的 `expected`。

- `desc`、`content` 非空；`content` 必须可直接作为角色/系统提示使用。
- `tool_ids`：仅填真实需要的工具名；不需要则 `[]`；**只能从用户请求中给出的「Available tools」清单里挑选，禁止编造清单外的工具名**。
- 不要输出 importance/weight 作为有效权重（系统会强制初始 weight）。

## 忌用

- 不要返回无法解析的散文。
- 不要留占位句（如「在此填写…」）。

## 注意

输出经解析后落库；格式错误会导致整次生成失败。
