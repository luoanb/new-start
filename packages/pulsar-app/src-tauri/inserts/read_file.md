# read_file

## 工具

读取活动工作区内的文本文件，支持按行分页（`offset` = 起始行，从 0 开始；`limit` = 最大行数）。对应 IDE 的 Read 能力。

参数（均相对活动工作区根路径）：

- `path`（必填）：要读取的文件路径。
- `offset`（可选）：起始行（0 起）；省略则从头读。
- `limit`（可选）：最大返回行数；省略则读到默认分块大小为止。

读取会将该文件标记为「已读」，这是之后用 `write_file` 覆盖它的前提。二进制文件会被拒绝。

返回 JSON：`path`、`content`（按行数组）、`start_line`、`total_lines`、`truncated`、`binary`。

## 对模型的期待

- 读取文件内容、定位代码、检查实现时调用。
- 大文件务必分段读：先读前若干行了解结构，再按需用 `offset` 续读，不要一次读到底。
- 依据返回内容回答，不要编造文件里没有的内容。

## 忌用

- 不要读取工作区之外的绝对路径（会被拒绝）。
- 不需要文件内容时不要调用。
- 不要用 `read_file` 代替 `list_directory` 去探索目录。

## 注意

- 只作用于当前 active 工作区；无 active 工作区时报错。
- 读取过的文件可被 `write_file` 覆盖；若文件在磁盘上被外部修改，写操作会报冲突。
