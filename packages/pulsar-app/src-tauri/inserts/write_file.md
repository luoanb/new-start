# write_file

## 工具

向活动工作区内写入文件内容。对应 IDE 的 Write 能力。

参数（均相对活动工作区根路径）：

- `path`（必填）：要写入的文件路径。
- `content`（必填）：文件的完整新内容。

规则：

- 新文件可直接写入（自动创建父目录）。
- 覆盖已存在文件必须先 `read_file` 读过，且文件在磁盘上未被外部修改，否则报错。
- 内容大小有上限，超大内容请拆分写入。

返回 JSON：`path`、`bytes_written`、`modified_ms`。

## 对模型的期待

- 创建新文件、全量改写文件时调用。
- 覆盖已有文件前，务必先 `read_file` 获取最新内容与已读标记。
- 写入后如后续还要修改，用 `search_replace` 做定点替换更安全。

## 忌用

- 不要写入工作区之外的绝对路径（会被拒绝）。
- 未读就覆盖已存在文件会失败——不要反复重试，先读再写。
- 不要把 AI 生成的大段内容一次性塞给一个超大文件，注意大小上限。

## 注意

- 只作用于当前 active 工作区；无 active 工作区时报错。
- 写操作会更新文件的「已读」状态为最新。
