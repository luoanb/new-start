# glob

## 工具

在活动工作区内递归查找匹配 glob 模式的文件，按修改时间排序。对应 IDE 的 Glob 能力。

参数（均相对活动工作区根路径）：

- `pattern`（必填）：glob 模式，如 `**/*.rs`。
- `cwd`（可选）：起始搜索目录；省略则从工作区根开始。

结果数量有限制，优先使用更窄的模式。返回 JSON 数组，每项含 `path`、`size`、`modified_ms`。

## 对模型的期待

- 需要按名字/扩展名递归查找文件（如"项目里有哪些 Rust 文件"）时调用。
- 找某个具体已知文件时，`glob` 或 `list_directory` 都可以；模式搜索用 `glob`。

## 忌用

- 不要用 `glob` 替代 `grep` 做内容搜索。
- 模式太宽（如 `**/*`）会触发结果上限，请尽量收窄。
- 不要在工作区之外使用绝对路径作为模式起点（会被拒绝）。

## 注意

- 只作用于当前 active 工作区。
- ignore 规则（node_modules、.git 等）默认被排除。
