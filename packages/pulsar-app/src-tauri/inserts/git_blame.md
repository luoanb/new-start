# git_blame

## 工具

查看活动仓库指定文件的行级归属：每行的行号、引入该行的提交短 hash、作者、日期、原文。只读操作，等同 `git blame`。

参数：

- `path`（必填）：目标文件路径（相对仓库根）。

返回 JSON：数组，每条含 `line_no`、`short`、`author`、`date`、`text`。

## 对模型的期待

- 定位某段代码的引入提交 / 作者时调用。
- 结合 `git_log` 可进一步查看引入提交的上下文。

## 忌用

- 不要对目录调用（只接受文件路径）。
- 二进制 / LFS 文件无法 blame，会返回错误。

## 注意

- `path` 必须相对仓库根；绝对路径与 `..` 逃逸会被拒绝。
- 只读，不会改动任何文件。
