# git_branch

## 工具

列出活动仓库的本地与远程分支，标记当前分支及各自上游。只读操作，等同 `git branch -vv` + 远程引用。

参数：无。

返回 JSON：数组，每条含 `name`、`current`（是否当前分支）、`upstream`（上游分支名，可空）。

## 对模型的期待

- 切换分支（`git_checkout`）前确认目标分支名与当前所在分支。
- 了解分支关系（当前分支是否跟踪远端）以判断 push / pull 行为。

## 忌用

- 不要用本工具创建 / 删除 / 重命名分支——本工具只读。

## 注意

- 远端分支名带 `origin/` 前缀，属同一列表。
- 只读，不会改动任何文件。
