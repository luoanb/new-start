# list_directory

## 工具

列出活动工作区内某个目录下的条目（文件与子目录），受工作区 ignore 规则过滤。对应 IDE 的目录列表（LS）能力。

参数（均相对活动工作区根路径）：

- `path`（可选）：要列出的目录；省略时列出工作区根目录。
- `ignore`（可选）：额外忽略规则数组（glob 或前缀），叠加在工作区默认 ignore 之上。

返回 JSON 数组，每项含 `name`、`path`、`is_dir`、`size`、`modified_ms`。目录优先排序。

## 对模型的期待

- 需要了解目录结构、查找文件是否存在时调用。
- 列表只覆盖一层（非递归）；需要递归查找时改用 `glob`。
- 根据返回结果回答，不要臆测目录里有什么。

## 忌用

- 不要用 `ls` 之外的目的调用它，例如读取文件内容请用 `read_file`。
- 不要请求列出工作区之外的绝对路径（会被拒绝）。
- 一次列一个大目录即可，不要为同一个目录反复调用。

## 注意

- 只作用于当前 active 工作区；无 active 工作区时报错，需先在「文件」视图添加工作区。
- 结果中已过滤 ignore 规则（如 node_modules、.git、target 等）。
