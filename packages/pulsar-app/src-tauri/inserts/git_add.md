# git_add

## 工具

暂存活动仓库的改动：传 `all=true` 暂存全部，或传 `paths` 暂存指定路径。写操作，无需确认。等同 `git add`。

参数（均为可选）：

- `paths`：要暂存的路径数组（相对仓库根）。
- `all`：`true` = 暂存全部改动。

返回 JSON：`{"ok": true}`。

## 对模型的期待

- 提交前先 `git_add`（all 或按路径）把改动移入暂存区。
- 只暂存本次提交相关的文件时用 `paths` 精确指定，避免夹带无关改动。

## 忌用

- 不要对未跟踪的大目录一次性全量暂存而不确认内容——先 `git_status` 看清再决定。
- 路径不得为绝对路径或含 `..`（会被拒绝）。

## 注意

- 无确认门禁，但仍是写操作：调用前确认暂存对象正确。
- `all` 与 `paths` 同时给出时以 `all` 为准（等价 `git add -A`）。
