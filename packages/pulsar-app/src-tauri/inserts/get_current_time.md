# get_current_time

## 工具

获取系统当前时间。调用时无需参数（传 `{}`）。

返回 JSON：

```json
{"unix_ms": 1755080000000, "utc": "2026-08-13T06:30:00.000Z", "local": "2026-08-13T14:30:00+08:00"}
```

字段说明：

- `unix_ms`：Unix 毫秒时间戳。
- `utc`：UTC 的 ISO 8601 时间（`Z` 后缀）。
- `local`：本地时间，含时区偏移（如 `+08:00`）。

## 对模型的期待

- 用户询问当前时间、日期或时区时调用。
- 直接依据返回结果回答，不要自行推算或猜测。
- 向用户展示时间时优先使用 `local` 字段。

## 忌用

- 不需要当前时刻信息时不要调用（该工具只返回调用那一刻的时间）。
- 不要伪造或修改返回的时间值。

## 注意

- 本工具无参数、无副作用、不会失败，可随时调用。
