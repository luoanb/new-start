# git_log

## 工具

查看活动仓库的最近提交历史（完整 hash、短 hash、作者、日期、标题）。只读操作，等同 `git log`。

参数（可选）：

- `limit`：返回条数上限，默认 30，钳制到 [1, 200]。

返回 JSON：数组，每条含 `hash`、`short`、`author`、`date`、`subject`。

## 对模型的期待

- 了解仓库演进脉络、定位最近改动时调用。
- 为提交信息 / 分支切换等决策提供历史上下文。

## 忌用

- 不要用本工具查看具体文件内容的行级来源——那用 `git_blame`。

## 注意

- 仅返回提交元信息，不包含 diff 内容。
- 只读，不会改动任何文件。
