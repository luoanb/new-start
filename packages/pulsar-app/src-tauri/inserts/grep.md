# grep

## 工具

在活动工作区内用正则表达式搜索文件内容。对应 IDE 的 Grep 能力。

参数：

- `pattern`（必填）：要搜索的正则表达式。
- `path`（可选）：限定搜索的目录（相对工作区根）；省略则搜索整个工作区。
- `case_sensitive`（可选，默认 false）：是否区分大小写。
- `multiline`（可选，默认 false）：`^` 与 `$` 是否按行边界匹配。
- `glob`（可选）：按文件路径过滤的类型，如 `*.rs`。
- `context`（可选，默认 0）：每个匹配前后各取几行上下文。

返回 JSON 数组，每项含 `path`、`line_number`、`content`（命中行）及可选 `before`/`after` 上下文行。匹配数量为返回数组长度。

## 对模型的期待

- 需要按内容定位代码（如"哪里用到了这个函数"）时调用。
- 先收窄 `glob`/`path` 再搜，减少噪音；结果有上限，命中过多时会截断。
- 依据返回结果回答，不要猜测其他文件中是否也有匹配。

## 忌用

- 不要用 `grep` 替代 `glob` 做文件名搜索。
- `pattern` 是正则：搜索字面特殊字符（如 `.`、`(`）时注意转义。
- 不要在超大目录上无过滤搜索，先限定 `path`/`glob`。

## 注意

- 只作用于当前 active 工作区；ignore 规则默认排除。
- 多行模式会让 `^`/`$` 按行匹配，适合逐行扫描。
