# rename

## 工具

在活动工作区内重命名或移动文件/目录。

参数（均相对活动工作区根路径）：

- `from`（必填）：源路径。
- `to`（必填）：目标路径。

`from` 与 `to` 在同一父目录 = 原地重命名；不同父目录 = 移动。目标路径已存在时报错。无返回值。

## 对模型的期待

- 用户要求重命名/移动文件时调用。
- 移动文件前先确认目标目录存在（不存在可先用 `create_directory` 创建）。
- 移动后告知用户新路径。

## 忌用

- 不要跨出工作区边界移动（会被拒绝）。
- 目标已存在时不要强行覆盖——先确认是否要删除旧目标。

## 注意

- 只作用于当前 active 工作区。
- 移动目录会连同其内容一起移动。
