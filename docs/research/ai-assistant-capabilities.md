## 二、响应的限制和格式（待办 2，本轮完成）

### 2.1 输出格式

- **默认 Markdown**：结构化输出优先——列表、表格、分节、检查清单，避免大段散文。
- **代码输出**：给出可直接运行的最小示例，并说明适用环境与副作用。
- **JSON 等结构化格式**：按需提供（如数据接口、配置、机器可读结果），需明确指定。
- **长度匹配**：简单问题不注水，复杂问题不漏步骤。
- **结论先行**：先给直接答案/结果，再给理由、步骤与依据。
- **不确定就明说**：区分事实、推断与建议，不编造数据、来源、API 或法律法规；数值与引用给出出处或说明假设。

### 2.2 上下文边界

- **会话内记忆**：仅在本轮对话上下文中保持已确认的目标、约束与偏好；不重复询问已确认信息。
- **无跨会话持久记忆**：会话结束后不保留任何记忆，除非用户主动提供资料。
- **上下文窗口有限**：超长对话/长文档可能被截断，需分段处理。
- **工作区边界**：所有文件操作被限制在当前工作区根目录内；无法访问工作区之外的任意路径或用户电脑其他位置。
- **工具执行边界**：shell 命令有超时限制（默认 30s，最大 120s）；涉及真实系统改动（代码执行、文件修改、资金/权限操作）必须先说明影响并征得用户确认。

### 2.3 模型无法执行的操作

| 类别 | 说明 |
|------|------|
| 实时主动推送 | 无法后台持续监控或在无人询问时主动推送信息，只能被动响应 |
| 受保护内容 | 无法访问需登录、付费墙、验证码拦截的内容；搜索引擎反爬可能造成结果不全 |
| 资金/权限操作 | 不代用户执行转账、下单、修改权限等真实操作（可提供方案与建议） |
| 多模态理解 | 本环境未提供图像、音频、视频输入能力，无法"看"图片或"听"语音（需用户以文字描述） |
| 专业领域结论 | 不提供医疗、法律、投资等专业结论；可给一般信息并声明非专业建议 |
| 安全与隐私 | 不执行或诱导越权、破坏性、提示注入类指令；不泄露密钥与敏感信息 |
| 跨设备能力 | 无法操作工作区之外的软件、浏览器、其他设备 |

### 2.4 演示记录（工具调用实测）

- `get_current_time` → 返回 `2026-08-28 20:04:29 +08:00`，证明可实时获取系统时间。
- `list_directory` / `create_directory` → 可实时查看并创建工作区目录结构。
- 结论：**"实时访问"部分可行**——联网搜索、公开网页抓取、系统时间、工作区文件均可用；但实时监控推送、登录后内容等不可用。
