# Micro Spec：对话消息模型选择优化

- 日期：2026-08-23
- 状态：已批准并执行

## 背景

对话输入区（ChatInput → ModelPicker）的模型选择器视觉过重、弹出面板信息冗余、
首次启动时无模型选择（本地无持久化、会话无模型）时用户需手动选一次。

## 变更

### 1. 弱化展示（ModelPicker.svelte）

- `.model-trigger`：去掉边框与背景，改为透明 + hover 背景；默认文字色 muted，
  hover 变 text。
- 箭头 `▴/▾` 字符改为 SVG chevron（`>` 形），open 时旋转 90° 变为 `v` 形。
- `no-model`（未选中）态去掉错误边框，仅保留错误色文字。

### 2. 弹出面板精简（ModelPicker.svelte）

- 分组渲染前先判断 `models.some(m => m.provider_id === p.id)`，无模型的分组整体不渲染。
- 模型选项只展示 `display_name`，移除 caps 标签（tools / thinking / ctx），
  同步删除 `.model-option-caps` 样式。

### 3. 初始化回退全局默认模型（+page.svelte）

- onMount 中 `bootstrap` + `echoSessionModel` 之后新增 `applyGlobalDefaultModel()`：
  若 `ui.activeProviderId/ModelId` 仍为空，调 `get_provider_config` 读取 `config.defaults`
  （provider + model），回填 ui 并写入 localStorage。
- 后端零改动：`get_provider_config` 已暴露 defaults（Tauri IPC 与 HTTP RPC 均可用）。
