# Spec: agent-app i18n (zh/en)

## Goal

- 要解决什么问题：GUI 目前所有文本写死为英文，需支持中英文切换
- 验收结果：切换语言后所有 UI 文本即时切换，偏好持久化

## Done Contract

- 什么算完成：所有面向用户的 UI 文本均支持中英文，语言切换器可用，切换即时生效，重启后保持
- 由什么证明：`pnpm check` 通过，每个组件验证中英文渲染
- 哪些情况仍算未完成：后端返回的 error message 未翻译（留到后续迭代）

## Scope

- In:
  - 轻量 i18n 模块（无第三方库，基于 Svelte 5 $state 的 store）
  - 翻译字典覆盖全部组件 UI 文本（StatusBar、SessionList、ChatArea、ChatInput、ChatMessage、SidePanel、SessionCreateModal、ThemeSwitcher、ToolCallBlock）
  - 语言切换器嵌入 StatusBar（与 ThemeSwitcher 并列）
  - 偏好持久化 localStorage

- Out:
  - 后端 Rust 错误消息的翻译（动态 error 消息）
  - 日期/时间格式本地化（保持 `HH:mm` 格式）
  - 第三方库的 i18n
  - 复数/变量插值的高级 i18n 特性

## Restated Understanding

- 我理解当前任务是：为 agent-app GUI 添加中英文双语支持，使用无第三方依赖的轻量方案，所有 UI 文本走 i18n 字典
- 当前核心目标是：完成 i18n 模块 + 全部组件翻译 + 语言切换器
- 当前边界是：仅前端文本，不翻译后端 error 消息，不处理复数/日期格式化等高级场景
- 暂不处理：Rust 端 error 消息翻译、日期格式本地化
