# Spec: Poller 配置（config.json）

## Goal

- 用 `.agent-app/config.json` 控制自动轮询启停与时长。
- 缺省保持暂停（与「默认不自动轮询」一致）。

## Done Contract

- 支持 `poller.enabled` / `poller.base_interval_ms` / `poller.assistant_interval_ticks`。
- Gateway 启动读取配置；`enabled=false` 或缺失 → Paused；`enabled=true` → Running。
- 文档 `storage.md` 反写；相关单测通过。

## Config

```json
{
  "poller": {
    "enabled": false,
    "base_interval_ms": 1000,
    "assistant_interval_ticks": 30
  }
}
```

- `enabled`：是否启动自动轮询（默认 `true`；2026-08-28 由默认关闭翻转，显式 `false` 才关闭）。
- `base_interval_ms`：调度器 tick 间隔毫秒（默认 `1000`，最小 `1`）。
- `assistant_interval_ticks`：Assistant 任务每隔多少 tick 触发一次（默认 `30`，最小 `1`）。
- 有效自动推进周期 ≈ `base_interval_ms * assistant_interval_ticks`。

## Validation

- `cargo test --lib poller`：5 passed（含 config 读写）。
- 本地 `config.json` 已写入 `poller` 段；重启 TUI/GUI 生效。
