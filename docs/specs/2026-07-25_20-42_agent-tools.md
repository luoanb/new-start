# Spec: Agent 工具调用 (Tool Calling)

## Goal

- 要解决什么问题：
  当前 Engine::chat() 是单次模型调用，模型无法调用工具/函数。Agent 场景需要模型能够根据用户意图触发工具执行（查时间、计算、调用外部 API），并将执行结果注入后续推理，形成"思考→行动→观察→继续"的循环。

- 验收结果：
  用户在对话中说出"现在几点"，模型调用 `get_current_time` 工具，返回结果后给出自然语言回答；整个过程在 TUI 中能看到工具执行的任务块进度。

## Done Contract

- 什么算完成：
  1. 模型支持 tool_calls 响应（finish_reason + tool_calls 数组）
  2. Engine 实现工具循环：调模型 → 检测 tool_calls → 执行工具 → 注入结果 → 重调模型 → 直到返回文本
  3. 现有三个技能（echo/calculate/time）注册为工具，模型可调用
  4. TUI 展示工具执行过程（TaskBlock 显示工具名、参数、结果或错误）
  5. 最多 10 轮循环保护，超限时返回 "Agent stopped: max iterations" 错误

- 由什么证明：
  单元测试覆盖 Tool 执行、响应解析、循环控制；手动测试 TUI 中 `/call` 触发工具调用。

- 哪些情况仍算未完成：
  工具结果不准确但模型仍然相信它并继续推理、Streaming 模式下工具调用不工作、并行工具调用不支持。

## Scope

- In:
  - 数据模型扩展：`ToolCall`, `ToolDefinition`, `ModelMessageRole::Tool`, `finish_reason`
  - Provider 适配：OpenAI-compatible 的 tools 参数发送与 tool_calls 解析
  - Tool 抽象层：`Tool` trait + `ToolRegistry`（替换 `SkillRegistry`）
  - Engine 扩展：`chat()` 增加 `tools` 参数，内部实现工具循环
  - 三个内置工具：`get_current_time`, `echo`, `calculate`
  - TUI 展示：`Tool` 执行作为 TaskBlock 显示在聊天区域
  - 循环保护：最多 MAX_TOOL_ITERATIONS = 10 轮

- Out:
  - 并行工具调用（模型返回多个 tool_calls 时只逐个执行）
  - Streaming 模式工具调用
  - 工具注册热加载（需要重启）
  - 文件读写工具
  - 记忆读写工具
  - 用户确认工具执行（auto-approve）

## 架构调整

当前：Engine 是单次对话编排，不感知工具。

```
Engine::chat() {
    store.get() → compactor → providers.call_model() → store.add_message()
    ↑ 单次调用，无循环                                                    ↑
}
```

调整为：

```
Engine::chat(input, options, tools?) {
    ┌──────────────────────────────────────────────────┐
    │  ① store.get() + compactor.ensure_fits()         │
    │  ② 构建初始上下文（含历史消息 + 用户输入）          │
    │  ③ 调模型（带 tools 定义）                       │
    │     ├── finish_reason = "stop"  → 跳 ⑤           │
    │     └── finish_reason = "tool_calls"              │
    │         ├─ 存 assistant(tool_calls) 到 store      │
    │         ├─ 逐个执行工具 → 工具结果存 store        │
    │         └─ 回到 ③（最多 10 轮）                  │
    │  ④ 存 assistant(text) 到 store                   │
    │  ⑤ 返回 ChatResponse                              │
    └──────────────────────────────────────────────────┘
```

### Engine 接口（扩展）

```rust
impl Engine {
    /// 原有单次对话不变（tools = None 时保持原行为）
    pub async fn chat(
        &mut self,
        input: &str,
        conversation_id: String,
        options: ChatOptions,
    ) -> AppResult<ChatResponse>;

    /// 带工具的对话（内部包含循环）
    pub async fn chat_with_tools(
        &mut self,
        input: &str,
        conversation_id: String,
        options: ChatOptions,
        tools: &ToolRegistry,
    ) -> AppResult<ChatResponse>;
}
```

`chat_with_tools` 调用流程：

```
1. store.get(conversation_id) → conversation
2. compactor.ensure_fits()
3. 构建初始上下文（含 compaction 摘要 + 未压缩消息）
4. 首次调模型（带 tools 定义）
5. loop (max 10):
   a. 解析响应：
      finish_reason = "tool_calls"
         → 存 assistant(tool_calls) 到 store
         → 逐个执行 tool
         → 存 tool(result) 到 store
         → 继续调模型（带完整历史）
      finish_reason = "stop"
         → 跳出循环
6. 存 assistant(text) 到 store
7. 返回 ChatResponse
```

### Tool 抽象层

```rust
// tool_registry.rs

#[async_trait]
pub trait Tool: Send + Sync {
    fn name(&self) -> &str;
    fn description(&self) -> &str;
    fn parameters(&self) -> serde_json::Value;
    async fn execute(&self, args: serde_json::Value) -> AppResult<String>;
}

pub struct ToolRegistry {
    tools: HashMap<String, Box<dyn Tool>>,
}

impl ToolRegistry {
    pub fn with_defaults() -> Self;
    pub fn register(&mut self, tool: Box<dyn Tool>);
    pub fn list_definitions(&self) -> Vec<ToolDefinition>;
    pub async fn execute(&self, name: &str, args: serde_json::Value) -> AppResult<String>;
}
```

三个内置工具：

| tool | 参数 schema | 行为 |
|---|---|---|
| `get_current_time` | `{}` | 返回当前毫秒时间戳 |
| `echo` | `{"message": {"type": "string"}}` | 回显 message |
| `calculate` | `{"expression": {"type": "string", "description": "数学表达式"}}` | 占位，返回 "计算器实现中" |

## 调用流程完整示例

```
用户输入: "现在几点？"

Engine::chat_with_tools:
  ① store.get("conv_xxx") → 加载会话
  ② compactor.ensure_fits() → 不压缩（消息少）

  ③ 调模型(带 tools=[get_current_time, echo, calculate])
     └── finish_reason="tool_calls"
         tool_calls=[{name:"get_current_time", args:{}}]

  ④ 存 assistant(tool_calls) 到 store
  ⑤ ToolRegistry.execute("get_current_time", {})
     → "1700000000000"
  ⑥ 存 tool("1700000000000") 到 store

  ⑦ 再调模型(消息历史 + tool_calls + tool_result)
     └── finish_reason="stop"
         output: "现在是 Unix 时间戳 1700000000000"

  ⑧ 存 assistant("现在是 Unix 时间戳...") 到 store
  ⑨ 返回 ChatResponse
```
