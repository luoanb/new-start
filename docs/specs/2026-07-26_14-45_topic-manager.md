# Spec: 课题管理工具 (Topic Manager)

## Goal

新增一个课题管理工具，用于管理项目进展。作为 Tool 注册到 `ToolRegistry` 中，在 Agent 模式下可由模型自动调用，同时在 TUI 中提供命令入口手动管理。

## Done Contract

1. `Topic` 数据模型定义
2. `TopicStore` 存储层：SQLite 文件 `./.agent-app/app.db`（App 级通用数据库，课题使用 `topics` 表），支持 CRUD
3. `TopicManager` 实现 `Tool` trait，包含 5 个工具注册到 `ToolRegistry`
4. TUI 命令：`/topics` 列表、`/topic new / <id> / <id> set / <id> delete`
5. 单元测试覆盖核心 CRUD + 工具调用
6. 数据库自动初始化（表不存在时建表）

## Scope

**In**:
- Topic 数据模型（不含删除的字段）
- TopicStore（SQLite 存储）
- TopicManager（5 个 Tool）
- ToolRegistry 注册（默认工具列表中追加）
- TUI 命令（`/topics` / `/topic ...`）

**Out**:
- 进度自动计算（保持手动设置）
- 状态流转校验

## 依赖

Cargo.toml 新增：

```
rusqlite = { version = "0.32", features = ["bundled"] }
```

`bundled` 特性会编译内嵌 SQLite，无需系统安装。

## 数据模型

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ScopeInItem {
    pub goal: String,
    pub done_contract: String,
    pub status: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum TopicStatus {
    Todo,
    InProgress,
    Paused,
    Done,
    Cancelled,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Topic {
    pub id: String,
    pub name: String,
    pub status: TopicStatus,
    pub description: String,
    pub scope_in: Vec<ScopeInItem>,
    pub progress: u8,
    pub extra: Option<serde_json::Value>,
    pub created_at: u128,
    pub updated_at: u128,
}
```

默认值：`status: Todo`, `description: ""`, `scope_in: []`, `progress: 0`, `extra: None`.

## 存储层 (TopicStore)

数据库位置：`.agent-app/app.db`（App 级通用数据库，所有结构化数据共用，课题只用 `topics` 表）

### 表结构

```sql
CREATE TABLE IF NOT EXISTS topics (
    id          TEXT PRIMARY KEY,
    name        TEXT NOT NULL,
    status      TEXT NOT NULL DEFAULT 'todo',
    description TEXT NOT NULL DEFAULT '',
    scope_in    TEXT NOT NULL DEFAULT '[]',
    progress    INTEGER NOT NULL DEFAULT 0,
    extra       TEXT,
    created_at  INTEGER NOT NULL,
    updated_at  INTEGER NOT NULL
);
```

- `status` 存枚举的 snake_case 变体名
- `scope_in` 存 JSON 数组字符串：`[{"goal":"...","done_contract":"...","status":"..."}]`
- `extra` 存可选 JSON 对象，不使用时为 NULL
- 时间戳存毫秒级 u128

### 接口

TopicStore 接收 `Arc<Mutex<rusqlite::Connection>>`（App 级共享连接），在构造函数中执行 `CREATE TABLE IF NOT EXISTS` 初始化。

```rust
pub struct TopicStore {
    conn: Arc<Mutex<rusqlite::Connection>>,
}

impl TopicStore {
    pub fn new(conn: Arc<Mutex<rusqlite::Connection>>) -> AppResult<Self>;
    pub fn init_table(&self) -> AppResult<()>;
    pub fn list(&self, status_filter: Option<TopicStatus>) -> AppResult<Vec<Topic>>;
    pub fn get(&self, id: &str) -> AppResult<Option<Topic>>;
    pub fn create(&self, name: &str, description: &str, status: TopicStatus, scope_in: Vec<ScopeInItem>, extra: Option<serde_json::Value>) -> AppResult<Topic>;
    pub fn update(&self, id: &str, update: TopicUpdate) -> AppResult<Topic>;
    pub fn delete(&self, id: &str) -> AppResult<bool>;
}
```

`TopicUpdate` 用于部分更新：

```rust
pub struct TopicUpdate {
    pub name: Option<String>,
    pub status: Option<TopicStatus>,
    pub description: Option<String>,
    pub scope_in: Option<Vec<ScopeInItem>>,
    pub progress: Option<u8>,
    pub extra: Option<Option<serde_json::Value>>,
}
```

`extra` 的 `Option<Option<T>>` 语义：`None` = 不更新该字段，`Some(None)` = 清空，`Some(Some(v))` = 设置为 v.

## Tool 实现 (TopicManager)

实现 `Tool` trait。TopicManager 内部持 `TopicStore`，方法签名与 Tool trait 兼容（异步 execute）。

在 `ToolRegistry::with_defaults()` 中追加注册。

5 个工具：

| 名称 | 描述 | 参数 | 返回 |
|------|------|------|------|
| `list_topics` | 列出所有课题，支持按状态过滤 | `status?: string` | 课题列表（名称+ID+状态） |
| `get_topic` | 查看单个课题详情 | `id: string` | 完整课题信息 |
| `create_topic` | 创建新课题 | `name: string`, `status?: string`, `description?: string`, `scope_in?: object[]`, `extra?: object` | 创建后的课题 |
| `update_topic` | 更新课题 | `id: string`, 其余字段均为可选 | 更新后的课题 |
| `delete_topic` | 删除课题 | `id: string` | 删除确认消息 |

## Gateway 集成

Gateway 在初始化时创建 `Arc<Mutex<rusqlite::Connection>>` 连接到 `.agent-app/app.db`，将此连接共享给 `TopicStore`、`TopicManager`（通过 ToolRegistry）和 TUI 命令处理。后续其他功能需要持久化存储时，也复用同一连接，只需加新表即可。

```rust
impl Gateway {
    pub fn new(store: ConversationStore) -> AppResult<Self> {
        let db_path = store.root().join("app.db");
        let conn = Arc::new(Mutex::new(
            rusqlite::Connection::open(&db_path)
                .map_err(|e| AppError::Internal(e.to_string()))?
        ));
        let topic_store = TopicStore::new(conn.clone())?;
        topic_store.init_table()?;
        // ...
    }
}
```

## TUI 命令

在 TUI commands 中新增 `TopicList` 和 `TopicAction(Vec<String>)` 命令：

| 输入 | 处理 |
|------|------|
| `/topics` | 调用 `TopicStore::list()` 并渲染列表 |
| `/topic new <name>` | 创建新课题 |
| `/topic <id>` | 查看单个课题详情 |
| `/topic <id> set <field> <value>` | 更新字段（支持 name / status / description / progress） |
| `/topic <id> delete` | 删除课题 |

会话列表 overlay 下方显示课题数统计行：`Topics: 12 (3 active)`
