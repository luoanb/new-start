# 终端域（Terminal）— 作用约定

> 本文件只约定终端域的**作用**：会话生命周期、事件流、Agent 执行桥接、远程访问。不约束实现方式；实现变化不影响本约定。
> 实现参照（非约定，随时可换）：`src-tauri/src/terminal/`（session / manager / events / commands / bridge / ws）。

## 1. 域是什么

> 🔒 用户盖章（2026-09-04）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

**终端域 = 应用里一切"跑一个真 shell"的地方。**

它管理真实的伪终端（PTY）会话——不是模拟的命令执行器：spawn 出来的就是用户的 shell，有完整的环境变量、TTY 行为、交互能力。两个使用方共享同一套会话与事件流：

1. **人**——用户在终端面板手动开终端、敲命令；
2. **AI**——Agent 的 `execute_command` 工具执行命令。

**两条路径在事件流上零区别**：AI 执行命令的实时输出与用户手动终端的输出走同一路广播，前端零区分渲染——用户在终端面板上能直接看到 AI 在跑什么。

## 2. 会话约定

> 🔒 用户盖章（2026-09-04）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

- **会话是唯一的操作单元**：spawn（可指定 shell 与工作目录，默认给常规初始尺寸）→ 写输入 → 调整尺寸 → kill，全程按 session_id 定位。
- **会话清单可枚举**：任意时刻可列出全部会话及元信息（shell、工作目录、运行中/已退出与退出码）。
- **退出可见**：进程退出后上报真实退出码，不静默消失；会话记录保留到被清理。
- **输出是字节流**：输出按到达顺序实时流出（高频小事件），消费方自行按流式渲染；二进制输出不丢弃。

## 3. 事件流约定

> 🔒 用户盖章（2026-09-04）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

- **所有会话的输出/退出事件汇入唯一发布点**，由它统一对外广播——不存在第二条旁路事件流。
- **双路扇出**：桌面前端经应用内事件通道监听；浏览器前端（远程模式）经 WebSocket 订阅。同一次输出两条路各收一份，**不重复消费同一字节流**。
- **流式语义**：订阅方处理不过来时允许跳块（丢的是中间显示块，不是会话本身），保证发射端永不因慢消费者阻塞。

## 4. Agent 执行桥接约定

> 🔒 用户盖章（2026-09-04）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

- Agent 工具执行命令 = **创建一次性 PTY 会话**执行、结束后回收——与用户手动会话走同一个管理器、同一套生命周期。
- 执行过程输出实时广播（同 §3 事件流）；命令的最终输出作为工具结果返回给 AI，**同时**用户在终端面板全程可见。
- core 层不直接依赖具体入口（桌面/服务器），只依赖本桥接——同一套桥接在 GUI 与远程模式下行为一致。

## 5. 远程访问约定

> 🔒 用户盖章（2026-09-04）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

浏览器前端通过 WebSocket 使用与桌面完全相同的终端能力：

- 帧协议：client→server 五种请求（spawn / write / resize / kill / list），server→client 五种响应（spawned / output / exit / list / error）；二进制输出编码传输。
- 与桌面共享**同一会话集合**：桌面开的终端浏览器能看到并继续操作，反之亦然。
- 消息信封与连接管理由网络层统一负责，本域只处理终端载荷。

## 6. 失败约定

> 🔒 用户盖章（2026-09-04）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

| 失败 | 表现 |
|---|---|
| spawn 失败（shell 不存在 / 目录无效） | 明确错误返回给发起方（用户命令或 AI 工具） |
| 写入已退出的会话 | 明确错误，不复活进程 |
| 退出 | 上报真实退出码 + 退出事件 |
| 订阅方积压 | 跳块保流式（§3），不影响会话与其他订阅者 |

## 7. 不变量（禁止事项）

> 🔒 用户盖章（2026-09-04）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

1. 一切 shell 执行必经本域的 PTY 会话——不存在绕过事件流的静默执行路径。
2. AI 执行与用户手动终端在事件流上不可区分（同一载荷、同一路广播）。
3. 会话输出永不缓存积压到阻塞：发射端永远先行。
4. 退出码必须真实上报，不得伪造成功。
