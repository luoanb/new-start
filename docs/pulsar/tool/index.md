# 工具域（Tool）— 作用约定

> 本文件夹按两层约定拆分：**注册层**（工具如何成为注册表合法一员）与**使用层**（一轮对话如何授权与执行）。不约束实现方式；实现变化不影响约定。
> 实现参照（非约定，随时可换）：`core/tool_registry.rs` / `tool_config.rs` / `dynamic_tool.rs` / `cmd_exec.rs` / `current_time.rs` / `mcp.rs` / `insert_catalog.rs`。

## 1. 域是什么

**工具域 = AI 能"动手"的全部手段的登记处与授权处。**

模型只会说话；让它读文件、跑命令、调 HTTP、用外部服务，都得通过这里登记的工具。本域管两件事：

- **登记**——工具是什么、凭什么进册子（[注册层](./registration.md)）；
- **使用**——一轮对话能用哪些、怎么执行、护栏是什么（[使用层](./usage.md)）。

工具的**具体能力**（文件操作、git、终端）属于各自领域——本域不实现任何业务能力，只做登记、授权与通用护栏。

## 2. 两层分工

| 层 | 文档 | 回答的问题 |
|---|---|---|
| 注册层 | [registration.md](./registration.md) | 一个工具凭什么进注册表？来源、门禁、声明、外部接入、重装配 |
| 使用层 | [usage.md](./usage.md) | 一轮对话带哪些工具？授权怎么决策、执行怎么容错、护栏怎么拦 |

两层以注册表为界：注册层只对注册表负责（进得来、说得清），使用层只从注册表取用（选得出、跑得动、拦得住）。
