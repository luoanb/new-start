# 工具注册层 — 作用约定

> 注册层约定"一个工具如何成为注册表里合法的一员"。使用层（授权 / 执行 / 护栏）见 [usage.md](./usage.md)。
> 实现参照（非约定，随时可换）：`core/tool_registry.rs` / `tool_config.rs` / `dynamic_tool.rs` / `mcp.rs` / `insert_catalog.rs`。

## 1. 登记单元

> 🔒 用户盖章（2026-09-06）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

- **一个工具一份自述**：name / description / 参数 schema / 执行体。登记后模型靠 schema 知道怎么调，执行体负责干活。
- **同名唯一**：同名登记冲突拒绝。
- **可枚举可查询**：注册表支持列出全部工具定义、按清单取定义、按标签取清单——这是使用层授权的取用基础。

## 2. 来源与门禁（三个来源维度）

> 🔒 用户盖章（2026-09-06）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

| 来源 | 是什么 | 进册子的条件 |
|---|---|---|
| `native` | 代码内置工具 | **必须携带对应的手册文档**（§6）：没有手册不许注册 |
| `config` | 配置文件声明的工具（HTTP / 命令模板，§4） | **声明即 schema**——配置里的声明就是它的全部自述，豁免手册要求 |
| `mcp` | 外部 server 发现的工具（§5） | 远端自带 name / description / schema，原样登记 |

来源与标签（§3）是正交的两个维度：来源决定进册子的门禁；标签只是可任意打、运行期可切换的分组标记，本层不赋予其语义。

## 3. 标签（仅是分组标记）

> 🔒 用户盖章（2026-09-06）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

- **注册层不赋予标签任何语义**：标签仅是一个标记，用于把工具归入分组。**可以任意打标**，不限固定集合。
- **运行期允许切换**：任意工具的标签可在运行期切换，切换即影响后续轮次的授权（使用层按当轮分组读取）。
- 打标时机自由：登记时可打（MCP 工具可在 server 声明里指定），也可运行期再打、改。
- 标签在本层的全部能力 = **标记分组**：提供"按组取工具清单"的查询。某个分组有什么意义（例如某组是否常驻对话），是使用层的授权策略，**不是标签自身的属性**。

## 4. 配置驱动声明

> 🔒 用户盖章（2026-09-06）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

两类由配置文件声明、无需写代码的工具：

- **HTTP 工具**：具名固定端点——URL 与方法在配置里写死，模型只能填参数占位，不能改端点。
- **命令模板工具**：固定命令模板 + 参数占位；**最终命令必须能通过命令执行安全护栏**（见 [usage.md §3](./usage.md#3-命令执行护栏)）才允许声明——护栏是这类工具能存在的前提，配置声明没有豁免。

配置读写约定：

- 文件缺失 = 空配置（不报错）；非法配置 = 可读错误（保存校验拒绝；启动期读到按空配置 + 警告）。
- 保存原子写回后**触发全量重装配**：应用以最后一次装配为准；装配期串行化，防止启动期后台装配与运行期手动重装配交错。

## 5. 外部 server 接入（MCP）

> 🔒 用户盖章（2026-09-06）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

- **声明式接入**：配置文件声明 server——stdio 子进程或 streamable-http 端点，可带环境变量、请求头、分组标签、显式禁用；不写代码。
- **启动期后台渐进装配**：应用先起来（本地工具立即可用），MCP server 逐个连接、发现工具、登记进册子。**单 server 连接 / 发现失败只警告跳过**——不阻塞启动、不影响其他 server、该 server 工具缺席。
- **状态可见**：每个 server 有连接状态（连接中 / 已连接 / 失败与原因），前端只读展示。

## 6. 自描述手册（insert）

> 🔒 用户盖章（2026-09-06）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

- 每个代码内置工具对应一份**模型可读的手册**（内嵌资源，按工具 id 索引）：工具是什么、产出什么格式、怎么用。
- **手册是登记门槛**：native 工具注册时强制校验手册存在——防止"模型不知道怎么用"的工具混进请求。
- 手册同时供**模型在对话中主动读取**（自描述目录能力）：模型可先查手册再决定怎么调用。
- 手册与工具同仓演进，能力描述与实际行为不得漂移。

## 7. 注册层失败约定

> 🔒 用户盖章（2026-09-06）· 本节经用户确认冻结：未经用户明确确认，不允许调整对应代码与修改本节文档。

| 失败 | 表现 |
|---|---|
| native 工具缺手册 | 注册失败（登记门槛） |
| 同名冲突 | 拒绝登记 |
| 配置非法 | 保存时拒绝；启动期读到按空配置 + 警告 |
| MCP server 连接 / 发现失败 | 警告跳过，该 server 工具缺席，其余不受影响，不阻塞启动 |
